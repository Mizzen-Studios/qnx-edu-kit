Build your own stock platform — explicit cooperative admission

This is a second, explicit route, not a relaxation of the Nov13 pinned handoff.

The default adapter still requires every original `PINS` value. No historical

receipt, failed run or artifact pin is republished or changed.

Trust boundary

The controlled builder executes exactly:

mkqnximage --type=qemu --arch=x86_64 --ram=512M --cpu=1 --ssh-ident=none --build

It creates a fresh private project with only authored

`local/snippets/qemu_options.edu` containing `-device edu`. No lesson,

startup or custom IFS snippets; the fresh own application is compiled separately

and transferred only after stock boots. It sources your named existing SDK

setup in a clean shell, retains only the documented SDK/path/licence environment

for the tool invocation, and records installed tool/diagnostic-output hashes,

recipe, source commit/tree/builder, generated input inventory, successful EOF/rc,

private build-log digest and all five output hashes. Tool measurements must be

unchanged after the actual command. SDK files, images, logs that may disclose

licensed content, credentials and learner notes stay outside Git.

A trusted owner supervises that invocation under the existing resource monitor,

stops/reaps the SDK, verifies actual zero QEMU and issues `stock-owner.json`.

Its SHA256 must be handed over separately by that owner; do not obtain a

trusted digest by hashing an untrusted download's adjacent JSON. Independent

admission requires that exact digest plus the explicitly named route. A manifest

or freely supplied artifact hashes alone are insufficient.

This is cooperative provenance, NOT cryptographic stock attestation, hostile

owner protection, licence certification or independent-human validation. A

trusted owner can lie; a malicious owner who controls the handoff and all local

files is outside the threat model. No offline hash format can prove otherwise.

The validator rejects accidental/tampered/mixed evidence relative to the trusted

handoff, not a fully rewritten owner history.

Existing legal platform prerequisites

Use the same canonical prerequisites, existing legal SDP8

second licence, paid resources, swap change or platform repair. Missing legal

setup is BLOCKED. SDK1GiB; native512MiB; CPU100%, HOST2GiB, swap0, nice15,

smp1, TCG256, reserve64. Active guest swap stops the build without changing it.

One trusted owner script holds the inherited exclusive

`/home/ubuntu/qnx-host/native-test.lock` descriptor through the full chain:

python3 scripts/stock_chain.py /absolute/private/owner-journey.sh

The script is trusted operator code, not downloaded build metadata. All paths

are absolute, outside the checkout, without symlinks, whitespace or traversal.

No foreign QEMU and no executable queued `*.sh` request may exist before SDK

start. Historical consumed `*.sh.running` markers are preserved, never deleted

or treated as authority; actual no-QEMU plus the exclusive lease establish that

no old guest is executing them. A controller exec timeout does not cancel the

original request: inspect its original result; never resubmit it blindly.

python3 "$EDU_REPO/scripts/stock_build_owner.py" \
  --controller "$EDU_CONTROLLER" --case "$EDU_SHARE/new-independent-case" \
  --environment /home/qnx/qnx800/qnxsdp-env.sh

The case must not exist. The owner clones the clean source into this private

shared case and dispatches the controlled builder as existing `qnx` user,

using the already configured queue only. It never installs or logs in. The

monitored SDK owner is reaped on success or failure; no native boot overlaps it.

A successful finish prints `STOCK_OWNER_SHA256=...`. Save that exact trusted

handoff value in `EDU_STOCK_OWNER_SHA256`; `EDU_STOCK` is this case's

HOST `stock` directory. Guest paths remain original metadata and are not

rewritten or dereferenced on HOST.

python3 scripts/stock_provenance.py verify --stock "$EDU_STOCK" \
  --owner-sha256 "$EDU_STOCK_OWNER_SHA256"

Your own notebook — same old oracles, new explicit admission

Initialize one fresh notebook and follow wrong → correct → finish.

flag name selects application-only compile/link; it does not select the platform

  --stock-owner-sha256 "$EDU_STOCK_OWNER_SHA256"
