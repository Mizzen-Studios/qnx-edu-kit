Host-only quick start

Host, repository root (Python 3 and POSIX shell, GNU make):

./verify.sh --host-only
make check-step1    # intentionally BLOCKED, nonzero
./verify.sh         # intentionally BLOCKED, nonzero

Host mode runs guard and framework tests, then explicitly SKIPs six live checks. Full verify never returns success in this milestone. Each check-step1 through check-step6 exits 2; make may report its own error status. make deploy is blocked and copies nothing. No DRYRUN pretends to build/deploy.

Release gates and limitations

See verification checklist, host test evidence and learning notes. Every edu register must be verified against a live device in the pinned QEMU before any register tutorial or publication. Eight accessible SVG design diagrams, Mermaid sources, six rich starter/solution specifications, a local static site and host lifecycle tests are now available. SDK review, actual secpol, all target code, live DMA/restart/trace, upstream claat export, two fresh target learner runs and mandatory on-QNX capture remain PENDING. No 45-minute completion claim is validated.

CI is host-only, not Stage-1 QNX acceptance. CI downloads no QEMU, SDK or target image. Local owner-authorized feasibility testing used apt QEMU and official checksum-verified Alpine Linux artifacts outside this repository; see TCG feasibility. No QNX SDK/image has been downloaded. Redistribution guard scans ignored/untracked files, names, signatures and selected markers; it is conservative, not a complete licence/content detector. SDKs, binaries, archives and images must stay outside this repo (also outside ignored folders). Python stdlib only; no dependencies are installed.
